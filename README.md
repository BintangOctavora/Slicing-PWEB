# Slicing-PWEB
# 🌟 Modern Responsive Portfolio ("Kentang")

Portofolio web profesional dan modern yang dirancang dengan antarmuka bersih (*clean UI/UX*), sistem perpindahan tema (*Dark/Light Mode*), serta tata letak yang sepenuhnya responsif untuk perangkat *mobile*, *tablet*, maupun *desktop*.

---

## ✨ Fitur Utama

- **🌗 Dynamic Theme Engine**: Sistem ganti tema instan menggunakan variabel CSS murni yang terintegrasi dengan tombol kontrol melayang (*floating UI*).
- **🎨 Custom SVG & Icons**: Menggunakan aset ikon SVG yang warnanya disesuaikan secara otomatis menggunakan variabel CSS (`fill`).
- **📱 Fully Responsive Layout**: Tata letak fleksibel berbasis CSS Flexbox dan *Media Queries* khusus yang dirancang presisi untuk layar HP (<600px), Tablet (600px-900px), dan Desktop (>900px).
- **🚀 Clean Navigation & Card Design**: Menunya tertata rapi dengan komponen kartu (*card containers*) interaktif pada bagian *About*, *Projects*, dan *Contact*.

---

## 🛠️ Teknologi yang Digunakan

- **HTML5**: Struktur semantik halaman web.
- **CSS3**: Variabel kustom (`--var`), Flexbox, *Media Queries*, dan *smooth transitions*.
- **JavaScript (ES6+)**: Logika interaktif dan manajemen tema.
